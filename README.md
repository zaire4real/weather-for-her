# 妳那邊的天氣

一個為重要的人準備的私人天氣頁。

> 不管妳在哪，我都想知道妳那裡冷不冷。

## 功能

- 點擊後才請求瀏覽器定位權限
- 顯示目前溫度、體感溫度、濕度、降雨機率與風速
- 顯示今日高低溫及未來 7 天天氣
- 依晴天、陰雨及夜晚自動切換背景
- 依天氣與時間顯示溫柔提醒
- 定位失敗時提供清楚說明與重試按鈕
- 手機優先的響應式設計

## 技術與隱私

網站是單一 `index.html`，沒有使用外部框架，也不需要 API key。天氣資料來自 [Open-Meteo](https://open-meteo.com/)。位置只會在瀏覽器中用來查詢當下天氣，不會由本網站儲存。

## 本機預覽

由於瀏覽器定位需要安全環境，建議直接開啟 GitHub Pages 網址。若要在電腦預覽，可在此資料夾啟動任何靜態網站伺服器，再使用 `localhost` 開啟。

## 客製化

直接編輯 `index.html` 就能更換標題、副標、天氣提醒與頁尾簽名。
